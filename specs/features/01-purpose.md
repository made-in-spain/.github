# Purpose

Hosts the [**`.github`**](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) meta-repository for the [**made-in-spain**](https://github.com/made-in-spain) organization.

| Deliverable | Role |
|-------------|------|
| [`profile/README.md`](../../profile/README.md) | **Public** organization profile at [github.com/made-in-spain](https://github.com/made-in-spain) |
| Root governance docs | `README`, `INSTRUCTIONS`, `CHANGELOG` for maintainers |
| `.github/` automation | Dependabot, CODEOWNERS, issue/PR templates |

The Made in SPAIN app is developed in a **private** repository. Public visitors use [github.com/made-in-spain](https://github.com/made-in-spain) and this **`.github`** repo only.
