# .github

Organization meta-repository for [**made-in-spain**](https://github.com/made-in-spain) — governance, automation, and the public org profile for **Made in SPAIN**.

**Made in SPAIN** is an iOS app that uses the iPhone camera or photo library to scan product barcodes and detect whether a product's country of origin is Spain.

## Organization profile

The visitor-facing page at [github.com/made-in-spain](https://github.com/made-in-spain) is rendered from [`profile/README.md`](profile/README.md).
